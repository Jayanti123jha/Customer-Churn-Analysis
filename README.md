# 📊 Customer Churn Analysis

## 📌 Project Overview
This project analyses customer churn for a subscription-based OTT platform to identify high-risk customers, understand churn patterns,
and evaluate revenue impact.

## 🛠️ Tools & Technologies
- Python
- Pandas
- SQL
- SQLite
- Jupyter Notebook

## 🎯 Objectives
- Analyse customer churn and retention rates.
- Identify high-churn subscription plans and regions.
- Segment customers based on churn risk.
- Analyse customer tenure and revenue at risk.
- Explore the relationship between support escalations and churn.

## 📈 Key Metrics
- Churn Rate & Retention Rate
- Churn by Plan Type and Contract Type
- Average Customer Tenure
- Average Revenue per User (ARPU)
- Revenue at Risk
- Churn by Support Escalation Status

## 💡 Key Insights
- Overall churn and retention performance.
- Customer segments with higher churn risk.
- Contract-wise and region-wise churn patterns.
- Revenue exposure associated with high-risk customers.

*Actual findings are documented based on the analysis results.*

## 💼 Business Recommendations
- Prioritise high-risk customers for retention.
- Investigate reasons for higher churn.
- Improve customer support and complaint resolution.
- Monitor churn KPIs to support business decisions.

## 🚀 Project Summary
This project demonstrates practical data analytics skills using Python, Pandas, and SQL to analyse customer behaviour, identify churn patterns, and generate actionable business insights for improving customer retention.
